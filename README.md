- Terraform

- VPC Multi-AZ
- IAM
- SSM
- EC2
- K3s
- Docker

Construir uma infraestrutura automatizada seguindo princípios de:

- Infrastructure as Code
- Least Privilege
- Alta disponibilidade
- Isolamento de rede
- CI/CD
- Segurança
